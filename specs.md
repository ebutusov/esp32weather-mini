# Project

Mini weather station for ESP32 and epaper display - T5_213. It displays weather from OpenWeatherMap.

## Description

The weather station has a tiny screen, so it should show just a few informations:
- the current location (configured via location code) and current weather conditions (BIG temperature in C, small pressure and humidity)
- the hourly forecast for next 12h (with 3 hour step, so 4 sections) showing temepratures and conditions like rain, snow, etc.) in a table, with icons

The information should fit o a tiny T5_213 screen. The units are metric. 

## Server component

The server component should be written in Python, split between 2 scripts.

The generator:
- downloads information from OpenWeatherMap (using provided config information, like location code)
- parses the current conditions and hourly forecast
- renders them to the in-memory image using TIL library
- converts the image into format that can be consumed directly by the e-paper display driver's framebuffer (already exists and works)
- saves the image in image directory (with paramter like --keep-last 2 so it will automatically delete old images)

The server:
- serves most recent image from the 'image' directory (the one generated by the generator) over http

## Device work cycle

The device (esp32) will work as follows:
- read the configuration from the config.json stored in spiffs
- connect to the wifi (ssid/password in config)
- request the image from the server
- fill the framebuffer with received data (image prepared by the generator on the server)
- display the framebuffer contents
- go to deep sleep for a period configured in config (disable epd before sleep)
